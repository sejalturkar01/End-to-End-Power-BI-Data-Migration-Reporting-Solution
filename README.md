# End-to-End Power BI Data Migration & Reporting Solution

## Project Overview

This project demonstrates the complete Business Intelligence workflow from data preparation to dashboard deployment using Microsoft SQL Server, MySQL, and Power BI.

## Business Process

### Phase 1 – Test Environment

* Connected Power BI to Microsoft SQL Server Test Environment
* Cleaned and transformed raw data using SQL and Power Query
* Created data models and DAX measures
* Developed interactive Power BI reports and dashboards

### Phase 2 – Production Environment

* Processed and validated Production Environment data
* Performed data cleansing and transformation in SQL Server
* Updated reports using Production datasets
* Ensured data consistency across reporting layers

### Phase 3 – Data Source Migration

* Migrated Power BI data source from SQL Server to MySQL
* Reconfigured connections and datasets
* Validated data integrity after migration

### Phase 4 – Deployment

* Created Power BI Workspace
* Published reports to Power BI Service
* Configured refresh schedules
* Delivered production-ready business dashboards
